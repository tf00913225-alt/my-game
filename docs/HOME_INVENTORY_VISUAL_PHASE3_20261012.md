# 主城／背包第三階段視覺施工

Work ID: HOME-INVENTORY-VISUAL-PHASE3-20261012

使用者於 2026-10-12 確認主城「場景主導、入口分層」手機／桌面預覽方向，並授權開始施工。背包以使用者提供的裝備環繞人物、下方物品清單參考圖為構圖依據，沿用本專案素材，不搬入參考遊戲圖片或資料規則。

## 本次定案範圍

- 主城保留正式夜景背景。中央出城冒險為最醒目的入口；休息、合成、任務、鍛造為兩侧的小型入口；角色與商店保留圖片但降低框線與光暈；秘寶、元素匣為低調成對入口；成就、公告、離線經驗、系統收成工具列。
- 手機保留中央街景留白，人物／商店與隊伍依可讀性向下排列；短螢幕可以自然垂直捲動。桌面常用入口與隊伍在右側，場景在左側。底部導覽沿用原 Owner 與美術。
- 隊伍完整姓名／等級、HP／SP 數字與條、秘寶與佈陣／更換功能全部保留，不採預覽中的無數字簡化條。
- 背包採緊湊頁首、清楚姓名切換、人物置中與六格裝備分列兩側。裝備標籤與格子成組，金幣／四分類／物品區／底部操作明確分區。桌面人物左、物品右。
- 背包保留六個現有部位、既有分頁容量、四分類、角色詳細、整理、分頁、售出與關閉／重新進入，不增加參考圖中本遊戲沒有的技能入口或裝備部位。

依 UI_GUIDELINES.md：css/00 維護主城入口，css/19 維護主城桌面與隊伍外觀，css/56 維護常駐秘寶／元素匣，adventure-entry CSS 維護出城入口；css/22 維護背包外觀／幾何，css/24 保留唯一物品區捲動契約。既有 index.html 只調整主城入口的語意分組，不另建頁面、stage、scaler 或投影鏈。

至少 360×800、393×873、412×915、768×1024、1366×768、1920×1080；加測短手機。使用正式 renderer 的六格穿戴、裝備／物品／材料、金幣與三人隊伍，不以空白樣板或 selector 存在代替画面。
