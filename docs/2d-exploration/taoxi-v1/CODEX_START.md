## 配置建議與整合要求

依 README 採用可逆初值：A／B 初開共 4 點、C 探索解鎖 2 點、D 主線解鎖 2 點、E 可用兩類條件 2 點。參考 `c1_06`「村民求援」及 `c1_16`「寨前情報」，讀過實際故事再定門檻。三名 NPC、六獎勵四描述、回原門口及原來源、四向行走均是建議，不是使用者已逐項確認。依故事與既有程式集中配置、記錄理由，無須重問家具等細節。

必要線索須能從已開區取得，避免循環鎖；線索可重讀，領獎後仍保有解鎖資格。使用有效既有物品 ID 與保守數量，未核對的名稱、API 或 owner 不可杜撰。

維持 single display／save owner 和帳號 UID 隔離。追查既有存檔、背包、展示入口；發獎與領取旗標一致提交並處理失敗。主線領獎函式及 `startStory`／`advanceDialogue` 不能當普通搜尋或對話 API；不另外加入商店、戰鬥、支線或採集。

概念圖不是現成正式素材。場景須有可用分層、碰撞遮擋及角色動作；不可整張帶介面／人物當背景，不以方塊或 emoji 冒充最終美術。素材不足須明列，暫用素材標清楚。正式新點陣素材按 `docs/IMAGE_ASSET_SPEC.md` 導入已驗證的無損 WebP，實際文字由 UI 呈現。
