# 《四象江湖傳》裝備／道具階級與四象色彩固定規格

> 狀態：**永久固定美術與 UI 規格**
>
> 除非專案負責人日後明確要求修改，否則任何裝備、道具、材料、設計圖、符咒、掉落物、背包格、商店格、物品卡片、合成介面、冶煉介面，都必須遵守本文件。
>
> 不得自行更換顏色、重新定義階級、增加其他稀有度配色。

---

## 1. 統一階級制度

遊戲中的「裝備」與「道具／材料」全部使用同一套階級制度。

正式階級順序固定為：

**白階 → 藍階 → 紫階 → 橙階 → 桃紅階 → 四象階**

所有裝備、材料、設計圖、礦石、寶箱與其他一般可分階級道具，全部統一使用這套六階。

**符咒為唯一明確例外：冰封符、隱身符、結界符只使用白階、藍階、紫階、橙階，不設桃紅階與四象階符咒。** 符咒四階仍必須使用本文件對應的白／藍／紫／橙色彩與階級名稱。

不得再另外使用「低階／中階／高階／完美」作為另一套正式稀有度制度。玩家應只需要辨識顏色，就能理解物品階級。

---

## 2. 白階

- 正式主色：`#D8D8D8`
- 視覺定位：灰白色
- 屬於最基礎階級
- 外框以低亮度灰白色為主，不需要強烈發光

---

## 3. 藍階

- 正式主色：`#42A5FF`
- 視覺定位：清晰藍色
- 比白階增加適度藍色光暈與外框亮度

---

## 4. 紫階

- 正式主色：`#B05CFF`
- 視覺定位：紫色高階物品
- 外框可加入適度紫色光暈，使其明顯高於藍階

---

## 5. 橙階

- 正式主色：`#FF9F38`
- 視覺定位：金橙色／橙色高階物品
- 外框亮度與光暈明顯高於紫階
- 橙階不是最終階級，其上仍有桃紅階與四象階

---

## 6. 桃紅階

- 正式主色：`#FF4FA7`
- 視覺定位：桃紅／洋紅色
- 屬於一般稀有度體系中的最高階級
- 稀有程度高於白、藍、紫、橙，但低於四象階
- 桃紅階外框可比橙階具有更明顯的能量光暈與高階感
- 桃紅階仍屬單一階級色，不得使用四色融合效果

正式階級關係：

**橙階 → 桃紅階 → 四象階**

---

## 7. 四象階定位

四象階為《四象江湖傳》的最高特殊階級。

四象階不是普通單色稀有度，不得用單一顏色代表四象階。

四象階必須使用以下四種元素共同形成外框：

- 火
- 水
- 風
- 土

四象階可用於例如：

- 四象套裝
- 四象裝備
- 四象設計圖
- 四象材料
- 四象特殊道具
- 四象相關終局獎勵

四象階必須具有明顯高於桃紅階的專屬視覺識別。

---

## 8. 四象元素固定色號

以下為正式固定色號。除非日後明確要求修改，否則禁止自行更換。

### 火元素／赤炎

- 主色：`#FF5A36`
- 呼吸亮色：`#FF8A5B`
- 暗部色：`#C93A1D`

定位：赤紅偏橙，具有火焰、灼熱、赤炎感。不得使用過度純紅或螢光紅。

### 水元素／寒泉

- 主色：`#42A5FF`
- 呼吸亮色：`#7CC7FF`
- 暗部色：`#1E6FBF`

定位：清澈冰藍，具有寒泉、冰水、靈泉感。不得過度偏深藍或藏青。

### 風元素／青嵐

- 主色：`#47D6A3`
- 呼吸亮色：`#7EF0C4`
- 暗部色：`#1E9B73`

定位：青綠、翠青，具有風靈、仙氣、青嵐感。禁止使用螢光綠或毒綠。

### 土元素／岩岳

- 主色：`#C89B45`
- 呼吸亮色：`#E5C06B`
- 暗部色：`#8A6730`

定位：金褐、大地金、岩石金色，具有厚重、岩岳、大地靈氣感。不得使用髒黃或過度暗沉咖啡色。

---

## 9. 四象外框固定配置

四象階外框預設固定分布：

- 左上：火／赤炎
- 右上：水／寒泉
- 右下：風／青嵐
- 左下：土／岩岳

四個角落分別使用對應元素主色，四條邊之間必須自然融合銜接。

禁止：

- 做成四個生硬分割區
- 將整個物品背景變成彩虹色
- 讓四色效果蓋過物品圖示本身

真正的視覺重點是：**四元素沿著外框融合**，而不是整張物品圖變成七彩。

---

## 10. 四象階呼吸效果

四象階必須具有專屬呼吸光效。

呼吸效果的本質為：

- 亮度
- 光暈
- 能量感

產生週期變化，而不是讓元素不斷變色。

例如火元素：

`#C93A1D` → `#FF5A36` → `#FF8A5B` → 再回到主色與暗色。

水、風、土依照各自三組固定色號進行相同邏輯。

禁止：

- 火變成水色
- 水變成風色
- 元素互相交換顏色
- 整圈快速彩色閃爍

---

## 11. 四象呼吸動畫節奏

- 建議完整週期：`2.4s ～ 3.2s`
- 建議動畫曲線：`ease-in-out`

整體效果必須：

- 柔和
- 緩慢
- 有生命感
- 有仙氣
- 有能量流動感

禁止：

- 快速閃爍
- 爆閃
- 高頻變色
- 霓虹跑馬燈
- 夜店燈效

---

## 12. 四元素呼吸不可完全同步

四個元素不要完全同時變亮與變暗。

每個角落可有約 `0.15s ～ 0.3s` 的細微錯開，讓玩家感覺「四象之力正在循環流動」。

但不能明顯形成跑馬燈，效果必須克制。

---

## 13. 四象外框建議光效結構

四象階外框建議至少包含三層。

### 第一層：固定元素主框

- 火：`#FF5A36`
- 水：`#42A5FF`
- 風：`#47D6A3`
- 土：`#C89B45`

### 第二層：呼吸外光

各元素在主色與亮色之間變化。

建議光暈透明度：

`30% → 60～70% → 30%`

### 第三層：細微元素能量表現

- 火：暖色熱流、赤炎微光
- 水：冰霧、水光、寒泉氣息
- 風：青色氣流、靈風
- 土：岩紋、大地靈氣、金褐光紋

第三層效果必須很輕，不得蓋過物品本身。

---

## 14. 各階級視覺強度

視覺華麗程度必須依照階級逐步提升：

1. 白階：最簡單
2. 藍階：輕微藍光
3. 紫階：明顯紫光
4. 橙階：較強金橙光
5. 桃紅階：高階桃紅能量光暈
6. 四象階：四色元素融合＋呼吸＋細微能量流動

必須讓玩家一眼看出階級高低，但所有特效都不能影響手機小尺寸 UI 的辨識度。

---

## 15. 手機 UI 可讀性規則

所有階級框縮小到背包格時仍必須清楚。

四象階尤其必須確保：

- 四色角落清楚
- 外框不能太細
- 呼吸光效不能過曝
- 中心物品圖片清楚
- 物品數量與文字不能被光效干擾

桃紅階與四象階必須明顯不同：

- 桃紅階：單一桃紅色高階光效
- 四象階：火、水、風、土四色融合呼吸框

---

## 16. 正式階級辨識規則

玩家僅看外框即可辨識：

- 灰白色 ＝ 白階
- 藍色 ＝ 藍階
- 紫色 ＝ 紫階
- 橙色 ＝ 橙階
- 桃紅色 ＝ 桃紅階
- 火＋水＋風＋土四色呼吸外框 ＝ 四象階

正式順序固定：

**白階 ＜ 藍階 ＜ 紫階 ＜ 橙階 ＜ 桃紅階 ＜ 四象階**

---

## 17. 所有系統統一套用

未來任何涉及物品階級的系統，包括：

- 背包
- 裝備
- 商店
- 掉落
- 副本獎勵
- 寶箱
- 素材
- 礦石
- 設計圖
- 符咒
- 合成
- 冶煉
- 物品詳情
- 裝備比較
- 裝備篩選
- 裝備出售

全部統一使用：

**白、藍、紫、橙、桃紅、四象**

這六階制度。

符咒依專案正式規則只開放 **白、藍、紫、橙** 四階；這是內容階級上限的例外，不是另一套顏色或命名制度。

禁止某個系統自行建立另一套「低／中／高／完美」之類的名稱與色彩。

---

## 18. 既有舊系統修改注意

如果舊程式目前仍存在：

- `low`
- `mid`
- `high`
- `perfect`

或：

- 低階
- 中階
- 高階
- 完美

等舊材料制度，後續應逐步統一成目前正式六階：

- `white` → 白階
- `blue` → 藍階
- `purple` → 紫階
- `orange` → 橙階
- `pink` → 桃紅階
- `four-symbol` → 四象階

但修改既有程式時，必須先確認：

- 舊存檔
- 資料結構
- CSS class
- 掉落邏輯
- 冶煉邏輯
- 其他系統依賴

禁止為了改名稱直接破壞既有存檔相容性。

## 20. 最終永久規則

《四象江湖傳》正式物品階級固定為：

**白階 → 藍階 → 紫階 → 橙階 → 桃紅階 → 四象階**

- 四象階為最高特殊階級
- 一般階級全部使用單一固定色
- 只有四象階可以使用火、水、風、土四色融合
- 四象階必須具有柔和呼吸效果

除非日後專案負責人明確要求修改，否則後續所有裝備、道具、材料與 UI 設計，都以本規格為唯一標準。
